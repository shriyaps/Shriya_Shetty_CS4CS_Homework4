CSS & JavaScript

I have used CSS within webpage and there are 3 ways to include CSS in a webpage as follows:

  1. Apply directly within the HTML element using the style attribute.

  2. Place style tag inside the head section of the HTML document.

  3. CSS can be written in a seperate .css extension and linked to the HTML document using the link tag.

The reasons CSS used in a webpage are:

  1. It improves user experience by making content easy to read & navigate.

  2. It is used to add colors, fonts & visual elements that make a web more attractive and professional.

  3. It controls how the content is displayed.

  4. CSS allows us to change the overall theme of the webpage based on the user's preference easily.

We also use JavaScript in webpage development. The main reasons are as follows:

  1. JavaScript adds interactivity by using event handlers like onlick, onchange, etc.

  2. JavaScript can change parts of a webpage without refreshing the whole page. For eg: changing the button color on just 1 click.

  3. It allows developers to run scripts directly in the client-side instead of sending request to the server which improves performance and efficiency. Eg: Form validation.
